# Digit Recognition Model

This project covers basics of Deep Learning Concepts such as FCNN, RNN, CNN, etc .

Early stopping is implemented to monitor the validation loss and stop training if it does not improve for 3 consecutive epochs.
Batch Normalization is also used to stabalize training.

The models which we have trained are : 

1. Fully Connected Neural Network
   1. loss = 0.09904731065034866 
   2. accuracy = 0.9739000201225281
2. Recurrent Neural Network
   1. Loss: 0.129432812333107
   2. Accuracy: 0.9639999866485596
   3. Precision: 0.9694980382919312
   4. Recall: 0.9599000215530396
3. RNN with Early Stopping
   1. Loss: 0.1140022799372673
   2. Accuracy: 0.9674999713897705
   3. Precision: 0.9739931225776672
   4. Recall: 0.9624999761581421
